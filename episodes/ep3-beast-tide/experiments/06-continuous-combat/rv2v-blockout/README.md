# rv2v 两层管线：3D Block-out → rv2v（2026-10-17）

在 2026-10-15 文字重构版之后，用户改为两段式制作：先用 3D 建模做**灰模低多边形预演（block-out）**，再把预演作为 Video 1 送进 Director 做 rv2v 出电影质感成片。

已验证：该管线解决了纯 r2v 的外观漂移（盾变刀、姿势崩坏），几何和尺度稳定。2026-10-17 跑出的三条（single-shot / building-impact / impact-separation）仍有三处不足：接触时机偏晚、被击者飞出画、攻击手不是张开的掌（以及轰楼用的是能量弹、看不到 Aegis）。本目录是按分析结论重排的版本。

## 为什么是两层

- **3D block-out 负责"动作、构图、时机、运镜"**：角色在画面里的位置、接触帧、相机运动全部由用户在 3D 工具里精确决定，不受模型自由发挥。
- **rv2v 负责"材质、光影、特效、最终质感"**：保留 block-out 的运动和构图，把灰色几何体替换成 PBR 材质的成片，加入接触闪、火花、震镜、运动模糊等。

## 文件结构

| 文件 | 用途 |
|---|---|
| [3d-blockout/](3d-blockout/) | 三段 3D 预演的**动作指令**（中文，含逐帧时间表和硬约束） |
| [groups/](groups/) | rv2v 的 Group 提示词，Shared Params 开启时用 |
| [complete-prompts/](complete-prompts/) | rv2v 自包含版，Shared Params 关闭时用（与 groups 二选一） |
| [manifest.json](manifest.json) | 素材、帧长、文件命名与修改点映射 |

## 第一步：制作 3D block-out

按 `3d-blockout/` 三份文件制作，规格：

- 24fps；灰色低多边形即可，不做材质/灯光/特效；建议分辨率 960×540。
- 帧长：06A 56 帧、06B 73 帧、06C 107 帧（即 17k+5 帧格，56f=2.33s、73f=3.04s、107f=4.46s）。
- 导出命名：`06A-palm-strike-source-56f.mp4`、`06B-wide-chase-source-73f.mp4`、`06C-bridge-strike-source-107f.mp4`，放进 `ComfyUI/input/`。
- 三段动作要点（详见各文件）：
  - **06A**：接触在 ~0.60s，张掌五指张开，接触后 1–2 帧内整体变速度，**全身始终在画面内**翻滚。
  - **06B**：开场即大远景翻滚、镜头前推（读出飞行距离），中途喷气、盾缩回、降到桥面穿掌，桥面完好。
  - **06C**：张掌在第 1 秒内击中桥面，断桥在同镜头内，Aegis 留在前景被抛出，刀只在 2.4s 后才出现。

## 第二步：Director rv2v

1. 选择 **r2v 参考主体生视频**，模型用 ref2va（已跑通的 pruned int8）；turbo 4-step LoRA 强度 1，4 steps / Euler / simple / CFG 1（沿用最近一次跑通的配置；若加 H3_Combat_V2，只改这一项以便归因）。
2. Shared Params 开启：公共框放 `../common-prompt.txt`；Picture 1–4 路径见 manifest。
3. 各 Group 挂 Picture 5（aegis-airborne-shield.png，只给身份与装备）。
4. 各 Group 在本段参考视频栏挂对应的 block-out 作 **Video 1**（视频槽与图片槽分别编号，已有 Picture 1–5 也从 Video 1 开始）；提示词把它当 motion plate，要求保留动作与构图、替换灰色几何。
5. Group 框粘贴 `groups/` 对应文件；Shared 关闭时才用 `complete-prompts/`。
6. 输出 864×480；逐段生成，不拼 12 秒长片。

## 验收（每段出片后逐帧核对）

**06A**：接触在 ~0.6s 且只有一次；接触后 1–2 帧内相对桥柱出现位移；能看出肘→肩→胸腰→髋→腿的先后反应；张掌不抓停、不贴盾；盾始终是盾；结尾仍在空中且全身在画面内。

**06B**：开场是大远景翻滚、镜头前推；前 0.8s 能读出飞行距离；喷气尾迹扭折；盾在中段缩回、无刀；结尾桥面完好、掌未触桥。

**06C**：掌在第 1 秒内击桥且无能量弹；先接触、后断裂、再落板；Aegis 全程在前景画面内；刀只在最后首次出现；巨兽胸甲完好。

## 剪辑落点

- **06A→06B 硬切**：切在接触闪光峰值（不用叠化）；切点前 2–3 帧顿帧、1 帧白闪、±40–50 短震，重锤音效与接触帧对位。
- 06B 开头的大远景保留完整，承担"展示飞了多远"。
- 06B→06C 在掌向桥面下落的动作中匹配切镜。
- 06C 掌击桥是二次冲击点，保留第 1 秒完整接触；上冲持刀运动中切出。
- 删掉等待和重复姿态，不裁掉接触后的位移；不用淡入淡出。

## 连续性

- 盾状态：06A 全程持盾 → 06B 前段持盾、中段缩回 → 06C 前段无投影、最后展开刀。
- 06A/06B 巨兽胸甲无刀伤；06C 不击中巨兽。
- 06C 结束已持刀，采用本管线时第 07 段开头删掉"盾转刀"的重复动作，改为"大刀已展开，继续绕肩接近"。

## 边界

灰模 block-out 是动作权威，但比例图仍需校准（16:1 目标）；rv2v 不改变 block-out 的动作，只负责成片质感。若 rv2v 出片仍出现握拳、踢腿、能量弹或人物出画，应先修 block-out，不叠加调整采样参数。
