|---|---|---|---|---|
| 06A | 中景 45° 斜角，接触点一次横向震镜 | 掌已逼近、举盾、约 0.60s 接触、1–2 帧内横向飞出 | 约 2 秒 | 0.00–0.55s（蓄力、接触闪、瞬间后挫） |
| 06B | 大远景 45° 斜角，镜头前推+下降 | 已在城市上空翻滚、巨掌追击、喷气纠正、盾缩回、穿掌降到桥面 | 约 2.5 秒 | 0.60–1.13s（远景翻滚追击、前推） |

合计目标约 8.5 秒源素材，剪成约 8 秒。硬切在剪辑中完成，模型生成的三段内部都没有切镜。

2. Shared Params 开启，公共框放本目录 common-prompt.txt，Picture 1–4 与上一轮一致（路径见 manifest.json）。
3. 三个 Group 的 Picture 5 仍为 `aegis-airborne-shield.png`，但提示词已明确它只给装备与材质、不给姿势——不要沿用图中的水平悬停姿态。
4. 三个 Group 都在本段参考视频栏挂载 `impact-motion-6.65-7.80.mp4` 作 **Video 1**；视频与图片分别编号，图片已有 1–5 也从 Video 1 开始。同一段片被三段重复使用，各段只借用 prompt 里指定的时间区间。
5. Group 框分别粘贴 groups/ 下对应文件；Shared 关闭时才用 complete-prompts/ 版本，二者不能混用。
6. 采样沿用已跑通配置：4 steps / Euler / simple / CFG 1 / LoRA 强度 1 / seed 888。本版只改提示词与新增 Video 1，便于把变化归因。

## 生成顺序与验收

先只跑 06A，逐帧核对：

- [ ] 接触出现在约 0.60s，全片只有一次接触闪光
- [ ] 闪光后 1–2 帧内，人物相对桥柱明显位移（至少一个身位）
- [ ] 能看到肘→肩→胸腰→髋→腿的先后反应，不是整体平移
- [ ] 掌不抓停、不贴盾推行，接触后立刻出现间隙
- [ ] 盾始终是盾，没有变成刀
- [ ] 结尾仍在空中，脚不落地

06A 达标后再跑 06B（核对：开场就是远景翻滚、镜头前推、能读出飞行距离、盾在 0.9–1.7s 段缩回、出片时桥面完好、掌未触桥），最后跑 06C（核对：掌在第 1 秒内击桥、断裂与落石可见、碎片抛人、刀只在最后 2.4s 后才展开）。任何一段失败，先改该段文本，不叠加修改采样参数。

## 剪辑落点

- **06A→06B 硬切**：在接触闪光峰值处切（这是参考片力量感的关键，不要用叠化）；切点前可做 2–3 帧顿帧、1 帧白闪、±40–50 短震，重锤音效与接触帧对位。
- 06B 开头的大远景承担"展示飞了多远"的职责，保留完整的前景翻滚与后景追击。
- 06B→06C 在掌向桥面下落的动作中匹配切镜，保持向右速度与同一动作轴。
- 06C 断桥处保留第 1 秒内的完整击桥冲击，这是二次冲击点；上冲持刀的运动中切出，不收干净。
- 优先删掉等待、重复姿态和过长的前半段逼近，不裁掉接触后的位移；不用淡入淡出。

## 连续性

- 06A/06B 巨兽胸甲无刀伤；06C 只展开刀、不击中巨兽。
- 06C 结束时已持刀，若采用这套实验，第 07 段开头删除"盾缩回并转为刀"的重复动作，改为"右臂大刀已展开，继续绕肩接近"。
- 盾的状态时间线：06A 全程持盾 → 06B 前段持盾、约 0.9–1.7s 缩回 → 06C 前段无投影、最后展开刀。
- 开头从已经飞行开始，可从第 05 段用喷射声提前切入。

## 边界

比例图仍未达到准确 16:1，本版验证的是打击节奏与运镜，不是尺度；正式批量渲染前仍需校准尺度、武器侧别、盾投影状态和桥梁空间关系。Video 1 含中文叠字、蹬腿和景别变化，提示词已要求不复制；若成片迁移出踢腿、白紫机甲或同体型对打，应换更接近掌击防守的运动素材，而不是调采样参数。这套测试单独保存，不覆盖正式第 06 段。
