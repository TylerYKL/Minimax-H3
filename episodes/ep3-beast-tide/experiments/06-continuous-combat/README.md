## Director 设置

保持现有4 steps / Euler / simple / CFG 1 / LoRA强度1 / seed888，先测试动作方案。Shared Params开启，公共框放本目录 common-prompt.txt；Group框分别放 groups/ 对应文件，不能放 complete-prompts/ 的完整版本。固定Shared图片1–4及本段Picture5的路径见manifest.json，与上一轮一致，无须增加图片。

三个Group都是单镜头，没有内部切镜。先生成06A检查冲击；若仍像匀速滑行，先改06A，不必消耗其余两段。不要仅靠提高整体播放速度代替受力反应。

## 镜头与剪辑

|源片段|主要动作|剪辑落点|成片建议占比|
|---|---|---|---|
|06A|高速接近、挡爪、被拍偏侧翻|在侧翻尚未结束时切出|约2.5秒|
|06B|接侧翻、喷射转向、从手指和桥沿之间穿过|手掌即将触桥、Aegis仍向右运动时切出|约2.5秒|
|06C|手掌击桥、桥段下坠、穿出碎块并展开刀|在向肩后上冲的运动中切出|约3秒|

上述时长是剪辑目标，不是固定截取区间；根据生成结果选取完整接触和反应。优先删掉等待和重复姿态，不裁掉接触后的身体位移。不用淡入淡出。A→B选相近侧翻角度，保持头部方向、右侧盾位置与向右速度；B→C在手掌下落过程中匹配切镜。若姿态/景别差异过大，应重生成下一镜，不用长叠化掩盖。

为了控制对比变量，第一轮只用既有图片。若独立镜头衔接明显漂移，再导出前段合适的末帧作为下一段新增Picture6，并在下一段定义其姿态/运动衔接用途；r2v参考图不保证固定首帧，不要只加图而不更新编号与文本。

## 特效与声音

模型内要求：接触点短闪、盾面短暂压缩、定向火花、被击后轨迹突变；桥面先断、烟尘后展开。发光常亮不能代替这些事件。

后期建议：爪盾接触处可用1–2帧局部曝光峰值、2–3帧短促镜头震动，接触后的短暂速度降低再恢复；都是起始建议，按素材调整，避免整屏持续闪烁或冻结。先保留可读的爪盾接触，不把过曝铺满整个过程。掌击桥面先给低频撞击，随后梁体断裂和落石；跨剪辑点延续喷射声与风声，避免每镜重新开始音效。源片段生成的音频可能不连续，需要剪接与混音。音乐和对白仍在后期加入。
