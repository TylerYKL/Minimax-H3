# R2V 短段快动作 V2

本包替代一次生成10秒的测试，分三次生成。尚未在H3实际渲染。时间、速度和冲击帧均为生成目标，并非精确控制保证。

| 段落 | UI时长 | 实际帧数/时长 | 参考图顺序 |
|---|---|---|---|
| 01 触盾与击飞 | 2秒 | 56帧 / 2.333秒 | 01-aegis, 02-titan, 04-city-building, 05-pov-composition |
| 02 撞楼特写与碎石 | 2秒 | 56帧 / 2.333秒 | 01-aegis, 04-city-building |
| 03 Nyx反应 | 1.3秒 | 39帧 / 1.625秒 | 03-nyx, 04-city-building |

导入对应workflow.json，在每组按表中顺序上传references目录的图片。每个文件独立执行。Ref2VA模型、25steps、CFG1、seed888及原采样器设置沿用。Turbo旁路；前两段Motion_Repair_V2=0.9，Nyx段旁路。权重需用户本机已有。

01与02的撞击有意重叠：剪辑时在01到达楼体前切到02的撞击接触，撞击仅保留一次。合计源素材约6.29秒，成片按动作剪短。若需要10秒成片，把时长留给环境与反应镜头。

本次改变：开头动作立即开始；盾臂—肩—髋的传力顺序；背部领飞、腿部拖后；20米/0.25秒的位移目标；固定建筑提供速度参照；撞楼镜头从距墙一个身长开始；接触点先爆碎片、烟尘随后扩散。全套生成提示词使用正向表达。

具体秒数和80米/秒只是叙事约束，模型可能偏离。复核到墙时间、盾手一致性、受击方向和碎片源头后再判断效果。01侧面视角与POV仍可能出现盾手翻转。

Nyx保留封闭面罩；78%装甲损伤文字继续由后期叠加。参考图仅绑定角色外观，当前包沿用旧资产，尚未验证跨段姿态连续性。
