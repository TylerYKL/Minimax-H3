# EP3 十秒多视角混剪

[观看/下载十秒成片](EP3-multiview-10s.mp4)

以实际生成的单段FL2V主线为基础，插入用户已生成的A第一人称、B怪兽肩后、C贴地和D俯拍。输出864×480、24fps、240帧、10.000秒，静音。

| 成片时间 | 镜头 |
|---|---|
| 0.000–0.375 | 侧面扑进 |
| 0.375–1.500 | A第一人称撞盾、分离 |
| 1.500–3.583 | 侧面落地、再扑、收盾 |
| 3.583–4.167 | B怪兽肩后挥刀命中 |
| 4.167–5.083 | 侧面命中后的击飞 |
| 5.083–6.208 | C贴地撞路障、落地 |
| 6.208–7.917 | 侧面恢复、换盾 |
| 7.917–8.958 | D俯拍交代位置 |
| 8.958–10.000 | 侧面收尾 |

所有片段原速硬切，不使用慢放、定格或重复源帧凑时长。多视角替换主线相应动作阶段，不再完整重播同一次攻击；主线本身的第二次扑抓保留。首尾目标帧保留，较长的举刀展示被肩后反打替换。此版重点是多机位与动作连接，尚未进行额外的局部速度重映射。

局限：独立渲染镜头中的兽体大小、刀刃外形、位置和背景有所差异；第一人称反弹中的形体拉伸仍在；接触闪光在切点附近可能持续数帧。本次剪辑不能修复模型形变，也不声称实现无缝三维空间连续性。没有添加声音、新特效或生成新动作。

用ffprobe核对240帧/24fps/10秒，抽查切镜和动作关键画面。逐帧剪辑范围见[edit-map.json](edit-map.json)。保留仓库目录结构，运行 `python render.py` 可重建（需要ffmpeg/ffprobe；会覆盖本目录输出）。
