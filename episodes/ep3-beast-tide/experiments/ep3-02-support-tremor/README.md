## 画面与动作检查

- Nyx：枪口短闪→能量沿枪口方向到达肩甲→石屑与兽体偏转，两次独立点射。不要只出现光束而没有受力。
- Lyra：绿色细丝实际连接肩甲；碎裂边缘对齐、合拢，伤员稍坐直，Lyra转头警觉。修的是装甲，不是改变人物外形。
- 震动：水波与石子先动，再让兽群向两侧让路，中央保持空。不能提前出现巨兽、巨足、断桥或大爆炸。

图像局限：让路镜头首尾兽群数量有轻微差异（边缘构图变化），需要检查视频中是否出现复制、融合或消失；如有，以可见的自然进出画调整剪辑或重做尾帧。独立机位的建筑背景并非同一三维场景的严格重投影。首尾帧和文字都不保证每发点射、每根手指及分秒准确执行。

## 严格十秒

完整三组输出应是253帧。先保留原片发回，检查动作和切点。可用以下脚本做保留各组首尾的十秒粗剪：

```sh
python conform_10s.py ALL-output.mp4 --output support-10s.mp4
```

脚本按72/96/72帧分配各组，少量均匀抽帧，不慢放、不裁掉组尾目标帧。输入不是253帧/24fps时会拒绝处理，避免错切；此时应先核对Director实际输出。它只校准总时长，不替代正式节奏剪辑。
