# 队友掩护与地面震动：实测与剪辑

[本段十秒](EP3-support-tremor-10s.mp4) · [接上前段的二十秒连续版](EP3-combat-support-20s.mp4)

用户上传三个单组结果。全为864×480、24fps、静音。Nyx73帧、Lyra124帧、震动73帧，总270帧=11.250秒。**Lyra实际为124帧而不是模板计划107帧**；仅凭视频无法确定是UI改动、版本对齐或其他设置导致。本次按实际素材剪辑，不调用要求253帧的旧conform脚本。

## 观察

- Nyx：约0.25秒与1秒附近能看到独立的紫色射击/命中闪光，近处小兽出现偏转与刮地水花。光束路径并非每个抽样帧都清晰，不能断言每发命中位置完全准确。镜头身份和越肩机位保持。
- Lyra：绿色能量作用于肩甲，肩部发光接缝逐渐闭合，伤员抬头坐直，Lyra最后抬头；整体剧情可读。效果较像宽光带包裹肩部，没有完全维持细丝设计；原片较长。
- 震动：兽群向两侧移动，中央通道打开，完整桥体仍在，未提前出现巨兽。前景石子跃起偏高、滞空偏长，有悬浮感；这是生成动作问题，当前剪辑没有消除。

## 本次处理

Nyx73→72帧，Lyra124→96帧，震动73→72帧。各段按比例抽帧、保留首尾，以24fps输出，不插帧、不慢放、不定格。医疗段播放速度约提高29%，其他两段几乎原速。分配为0–3秒点射、3–7秒修复、7–10秒震动让路，直接硬切三个机位。

实际抽帧索引见[edit-map.json](edit-map.json)，从0开始。原始素材保存在sources/。十秒版240帧，连续二十秒版480帧，均经ffprobe验证24fps、精确时长、无音轨；输出关键画面已检查。二十秒版开头使用已提交的multiview-10s-edit/EP3-multiview-10s.mp4。

本轮未增加音效、配音、音乐或生成新动作。剧情暂接到兽群让路；下一段可按既定顺序进入30米巨兽揭示和Aegis起飞。
