# Aegis POV：巨爪迎面压近

这个镜头从Aegis眼睛的位置看向巨兽，用巨爪沿镜头轴迅速逼近、前后景遮挡和手掌投影扩大来表现压迫感。镜头结束在即将接触能量盾的一刻，随后可以切到侧面接触镜头。

本包包含新首尾图、正向英文H3提示词、单镜头FL2VA工作流。尚未在H3实机验证。

## 使用

1. 导入 `pov-claw-workflow.json`。
2. 将 `frames/pov-start.png` 上传首帧槽，`frames/pov-end.png` 上传尾帧槽，核对缩略图。
3. 界面请求时长 **1.3秒**，按当前Director对齐规则输出 **39帧 / 24fps = 1.625秒**；提示词使用四舍五入后的实际长度1.63秒。请以本机显示和输出核对。
4. FL2VA、25步、CFG1、res_multistep/simple、shift12/3、seed888、864×480、24fps。Turbo与Combat旁路，段间引导关闭，静音输出。

## 镜头设计

- 眼睛位置的第一人称：前景为Aegis右前臂和金色能量盾，远处为巨兽。
- 巨兽掌心沿视线轴正面接近，爪尖从中央向画面边缘扩张。
- 相对稳定的楼房和月亮提供运动参照，掌部逐渐遮挡巨兽躯干与天空。
- 能量盾近景维持稳定尺寸，巨爪的变大来自真实接近。
- 最后一瞬保留盾与巨爪之间的窄缝，为侧面冲击镜头提供剪切点。

## 评估

检查巨爪是否实际向观众接近、手指结构是否稳定、前景是否保持第一人称、能量盾与掌心是否保持清楚的前后关系。镜头任务是迎面威胁与压迫感；接触、击飞和建筑碰撞由后续镜头承接。

首尾图与提示词属于生成约束，不能保证中间帧速度。若模型仍将逼近过程均匀拉长，可从输出中选取有效的接近区间做短插入镜头。
