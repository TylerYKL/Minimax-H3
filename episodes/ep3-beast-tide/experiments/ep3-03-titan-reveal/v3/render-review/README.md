# V3 成片节奏剪辑：5.5秒

使用用户上传的四段 V3 H3 视频，按落脚、全身、起飞、跟拍顺序剪辑。输出864×480、24fps、132帧、5.500秒，静音。

[播放／下载视频](EP3-titan-V3-cut-5.5s.mp4)

| 成片时间 | 素材 | 源片帧范围（从0计，含末帧） | 输出帧数 | 处理 |
|---|---|---|---:|---|
| 0–1.00秒 | 01-foot | 0–35 | 24 | 1.5倍时间压缩，保留触地和压实 |
| 1.00–2.25秒 | 02-scale | 0–29 | 30 | 原速短全景 |
| 2.25–4.00秒 | 03-launch | 0–47 | 42 | 约1.14倍时间压缩，在升空途中切镜 |
| 4.00–5.50秒 | 04-follow | 0–47 | 36 | 约1.33倍时间压缩，保留短跟拍 |

以抽帧实现时长压缩，采用直接切镜。未增加补帧、音效或新的生成画面。源片远景与中景的武器姿态和空间关系差异仍然存在，剪辑仅缩短停留、改善节奏，不能修复三维连续性。这是登场与起飞过渡段，尚未包含交锋。

`edit_cut.py` 接受四段原视频，顺序为 FOOT SCALE LAUNCH FOLLOW；使用 `--output` 指定新的输出文件。运行需要 ffmpeg/ffprobe。
