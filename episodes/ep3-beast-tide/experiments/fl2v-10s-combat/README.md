# 十秒 FL2V 战斗测试包

目标成片为十秒：挡盾反弹 → 能量刀反击 → 撞路障、落地、追进。**本包已生成五张精细关键帧、三个独立工作流及提示词；H3 视频尚未渲染，最终动作剪辑待用户返回素材。** 不将静态图轮播当作生成视频。

第02段尾帧与第03段首帧共用同一张图。第01到02段通过切镜省略收盾出刀。第02段是较低侧面构图，第03段延续击飞后的较宽构图；本轮没有强行加入绕轴或上帝视角，优先验证动作衔接。岩兽处在更近的前景时视觉上偏大，尚需检查H3是否保持体型；本测试仍是小兽，不是30米巨兽。关键帧本身不能保证中间的接触、速度和身体受力。

## 使用

1. 三个JSON分别用ComfyUI打开，**不是导入导演包**。选择 `fl2v — 首尾帧生视频`，每个工作流一个分组。
2. 将表内两张图片分别上传到该分组的**首帧、尾帧槽**。确认缩略图与文件名。JSON中的名称是待上传文件的占位引用，不会自动上传到你的电脑。
3. 模型 `minimax_h3_fl2va_pruned_int8_convrot.safetensors`；25 steps、CFG 1、res_multistep/simple、shift video/audio 12/3、seed 888 fixed、864×480、24 fps。参数以本地Director官方FL2V示例为依据，不代表最优动作参数。
4. Turbo与Combat节点均旁路。模板可能仍显示原Ref2V LoRA名字，**保持灰色旁路，不要启用**。无需额外共享参考图、团队合照或灰模视频。CLIP/VAE沿用已有工作流的文件名，如本机名称不同请选择对应文件。
5. 段间引导关闭；CreateVideo的audio断开，Director的audio_vae保持连接，静音导出。三个模板完成了静态结构检查，未在ComfyUI/GPU运行验证。
6. 先跑01；如果出现一直顶盾、形变过渡或终点前长时间悬停，不继续批量跑02/03。若01可用，再完成其余两段并上传三个MP4用于正式剪辑。

73、107符合17k+5帧对齐。总原素材253帧约10.542秒，多出的帧用于后期取舍，**不要简单裁尾丢掉FL2V目标尾帧**。

## 后期

提供的 `assemble.py` 将三个24fps视频按72/72/96帧取样，保留各段首尾帧，输出严格十秒的静音粗剪：

```sh
python assemble.py shot01.mp4 shot02.mp4 shot03.mp4 --output rough-10s.mp4
```

需要Python 3、ffmpeg、ffprobe。只做少量均匀抽帧和拼接，**不是正式快打变速方案**。第02/03段共用边界图，正式剪辑时可去掉重复边界帧。

正式剪辑待成片后逐帧确定：接触瞬间保留短闪光，删除持续顶盾；压缩分离及空中漂浮；保留落地受力；在挥刀和撞路障处接动作。3/3/4秒为可调整配额，最终总计240帧。若有效动作不足十秒，应补镜头，不能靠慢放或停帧凑时长。本包没有生成爆炸音效或配乐。
