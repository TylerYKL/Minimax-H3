## 借用什么，替换什么

该短片表现的是同体型机甲蹬击，**不是现成的巨兽掌击**。可借用的内容是接触短促、被击者速度突然增加、四肢滞后、双方迅速分离。提示词明确将攻击替换为巨掌击盾，外观仍用图片，尺寸仍要求30米与1.88米。

原视频含可见中文叠字和一次景别变化，均保留在参考短片中，提示词要求不复制。可能仍出现踢腿、同体型对打、文字或相同镜头的迁移；这不是已经验证的动作重定向。

## 如何判断结果

与 `MiniMaxH3_Director_00007_.mp4` 比较：掌盾接触后是否马上出现横向位移；是否缩短贴盾推行；是否保持空中侧翻；是否引入了踢腿、白紫机甲或比例缩小。只有动势改善且没有引入明显错误，才继续06B。

图片比例误差尚未解决，视频参考也不能自动修复。若生成复制了踢击，应换成更接近掌击防守的运动素材，而不是同时改很多采样参数。
