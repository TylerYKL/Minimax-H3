# EP3：r2v单次生成10秒，多视角击飞与队友反应

本实验使用**一个r2v素材组、一次生成**，在同一提示词内部要求六个摄影机镜头。参考图提供身份、场景和构图，不设首尾帧槽。原有FL2VA包保持原样。

## 导入与模型

1. 导入`r2v-single10-workflow.json`。
2. UNET选择 **minimax_h3_ref2va_pruned_int8_convrot.safetensors**。此模式使用Ref2VA，区别于前版FL2VA。模型文件需要本机具备；包内不含模型权重。
3. Director模式为`r2v — 参考主体生视频(Reference to Video)`。应显示**1个素材组**，界面时长10秒。
4. 把下表5张参考图依次上传到该组的参考槽。公共参数关闭，完整六段式提示词放在组内，避免重复拼接。槽位编号必须与提示词一致。
5. 25步、CFG1、res_multistep/simple、shift12/3、seed888、864×480、24fps；静音；Turbo旁路。Motion Repair V2=0.9。可选触发词已写入提示词。
6. 如需相同提示词关闭LoRA做对照，使用`r2v-single10-baseline-workflow.json`。

Motion Repair与当前Ref2VA int8加载器的实际权重兼容性尚待本机验证。检查控制台是否出现键不匹配或大量未加载提示。单次生成时0.9权重作用于整段，包括Nyx；这里没有承诺镜头级LoRA开关。作者对0.9的建议属于单独使用的起点，不是该镜头已验证的最佳值。

## 提示词内的时间安排

| 时间 | 镜头职责 |
|---|---|
| 0–1.0秒 | Aegis第一人称，巨爪迎面逼近 |
| 1.0–1.8秒 | 侧面触盾、受力、与巨爪分离 |
| 1.8–2.3秒 | 高位远景，迅速被击飞向左侧建筑 |
| 2.3–5.2秒 | 撞墙、室内爆闪、局部支撑失效 |
| 5.2–8.2秒 | 地面仰视，碎石坠落与尘浪 |
| 8.2秒至结束 | Nyx警报与担心反应，约1.9秒 |

前2.3秒承载短促攻击与位移，之后用建筑损伤后果和队友反应完成十秒。这些切点是生成目标，不是后期剪辑的硬切点；模型可能合并镜头、改变切点或拉长击飞。若失败，应先判断遗漏了哪个镜头或动作，不能仅凭提示词认定多视角成功。

## 10秒与帧数

当前查阅的Director前端采用17k+5对齐。10秒×24fps=240帧，向上对齐为243帧，原生输出预计10.125秒；参考示例工作流也使用10秒/243帧。包内`finish_10s.py`检查输入为243帧/24fps后，裁去末尾3帧，得到240帧/10.000秒。

```sh
python finish_10s.py EP3_r2v_single10_motionrepair_00001_.mp4 --output EP3-r2v-exact10.mp4
```

最终Nyx镜头实际位置确认后，再在该镜头上添加78%等可修改HUD读数。此包仅制作输入素材、提示词和工作流，尚未运行H3。
