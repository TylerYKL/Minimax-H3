# 06A 两镜独立生成，再剪成两秒

针对两秒版本实测中「接触后仍慢推盾，击飞偏慢，坍塌不清楚」的问题，将侧面接触与俯视破坏分成两次生成。A 允许慢镜逼近；B 从已经被击飞开始，全程正常高速。最终两秒节奏由选帧和剪辑控制。这是提示词与操作包，尚未生成新视频；manifest.json 不能直接作为工作流导入。

## Director 操作

1. 在现有 R2V 工作流中建立两个独立分组，命名 `06A-A` 和 `06A-B`。它们是原 06A 的两个机位，不是旧实验的 06B/06C。
2. 共享提示词用本目录 `common-prompt.txt`。A 的 Group Prompt 用 `groups/A-anticipation-impact.txt`；B 用 `groups/B-overhead-flight-collapse.txt`。全文替换，不叠加旧提示词。
3. 两组都沿用共享 Picture 1–4 和本地 Picture 5。Picture 5 只供外观；A 开场盾关闭，B 开场盾已开启。
4. **这轮移除两组的 Video 1，并确认共享区域也没有继承的视频。** 旧参考是等身机甲踢击且带文字，不能准确提供本次俯视飞行与坍塌；本版提示词没有引用它。这是一次制作方案调整，不是单变量 LoRA 测试。
5. **关闭段间引导／引用上段。** B 需要直接从俯视高速位移开始，先不让 A 的慢镜尾部和侧面机位进入 B 的条件。两个分组分别选择运行、分别保存视频，以便剪辑。
6. 每组目标生成时长设为 **2.0 秒**，24 fps。当前检查过的 Director 帧数规则会对齐为 56 帧，约 2.33 秒；两个原始片段共约 4.67 秒，不是直接拼接后就得到两秒。
7. 保持当前有效模型链：Ref2VA UNET → ref2v Turbo 1.0 → Combat V2 0.4 → Director。4 steps、euler/simple、CFG 1、seed 888、video shift 12、audio shift 3。两个提示词均已包含 `prfight2, prfin1`。

若不用共享提示词，分别使用 `complete-prompts/` 下的完整版本，并确保相同图片槽仍绑定到每组。不要同时粘贴完整版本与共享提示词。

## 两镜交接状态

| 项目 | A 结束 | B 开始 |
|---|---|---|
| 人物动作 | 掌盾已分离，背部领先向右高速离开 | 已离开指尖，背部领先向右高速飞行 |
| 护盾 | 右臂固定，已激活、完整 | 同一状态 |
| 推进器 | 受击时熄灭 | 无喷焰，不是主动巡航 |
| 建筑 | 右侧十二米外，原有裂缝但无新撞击洞 | 同一外观和距离，撞墙前无新洞 |
| 摄影机 | 侧面中广景 | 固定高位俯视，可同时看见路线和外墙 |

场景文字锁定一栋四十米、十层、平顶、灰混凝土、暗窗格建筑，最右边缘有细长红色竖板。它是本轮共同的目的地标记，不是新参考图；文字不能保证两个独立生成的建筑完全一致。接片若出现外观或空间跳变，应先校正共同场景参考，而不是用光效遮盖。

## 生成提示词内部的时间目标

- A：0–0.15 秒巨爪快速进入；0.15–1.20 秒减速逼近；约 1.20 秒恢复高速并开盾；约 1.30 秒击中；约 1.40 秒分离；余下时间只供人物离开画面的剪辑余量。
- B：开场已经高速飞行；约 0.20 秒背部撞墙；随后墙体碎裂、柱体失稳、楼板断开，上方结构开始下沉；片尾仍在坍塌，不加入逃生。

上面是原始片段的导演目标，**与最终剪辑时间不同**，也不是模型逐帧保证。官方 H3 skill 的常规建议为 4–15 秒，本次按用户要求试验两秒短段。

## 最终两秒剪辑表（24 fps，共 48 帧）

按实际画面中的事件选段，不要盲目按生成提示词的时间裁剪。

| 成片帧，零起始 | 成片时间 | 从哪里选 | 处理目标 |
|---|---|---|---|
| 0–23 | 0.000–1.000 秒 | A：逼近至开盾前 | 保留脚底喷射、压缩空气和越来越近的爪子；轻微变速适配一秒 |
| 24–25 | 1.000–1.083 秒 | A：盾从无到有 | 压成两帧可读的瞬间展开，不停格 |
| 26–27 | 1.083–1.167 秒 | A：实际命中与首次后折 | 保留短闪和受力，不保留后续持续推盾 |
| 28–31 | 1.167–1.333 秒 | B：开场飞行至墙前 | 硬切俯视，四帧内越过间距；实际飞行过慢时压缩此段 |
| 32–47 | 1.333–2.000 秒 | B：身体撞墙至结构下沉 | 从实际接触开始选，优先保留可见的裂开、断板、下沉，而非长时间烟尘 |

硬切发生在受击之后，不做交叉溶解。接触附近优先普通帧采样，先不使用光流插帧，避免手、盾和人物粘连。末段如果没有真实的结构下沉，剪辑加速也不能创造坍塌：将 B 记为未通过，而不是只留下烟尘当作完成。

变速后重新对齐短促盾击声、位移声和撞墙声；不要把慢镜长低鸣带入后半段。白色残影若未生成，可后期沿实际位移轨迹补短拖尾，但不可用它掩盖人物未离开起点的问题。本包未执行剪辑或音效制作。

## 验收与下一次回传

先分别检查 A、B 原片：A 至少要有可选的开盾、接触和后折；B 必须有清楚的起点离开、身体撞墙和结构坍塌起势。若 A 长时间贴盾，只选最早真实命中的瞬间；若根本没有受力反应，则需要重生成 A。若 B 从悬停开始或仍没有建筑破坏，则重生成 B，无需重跑 A。

请分别导出 A、B 原始视频再回传。可以依据实际接触与破坏帧来剪接评估；时间码写得精确不代表实际已命中目标。巨兽与 Aegis 的 30 米/1.88 米比例也需要逐镜复核。
