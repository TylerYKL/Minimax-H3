# A–D 实际渲染检查与剪辑

[3.75秒快节奏试剪](ABCD-action-cut-3.75s.mp4) · [8.625秒原速顺接](ABCD-original-8.63s.mp4)

用户提供A/B/C各56帧、D39帧，全部864×480、24fps、无音轨，共207帧。原速顺接保留全部源帧。试剪90帧，共3.750秒；没有补帧、定格、重复动作、新特效或音效。

| 镜头 | 观察 | 剪辑取舍 |
|---|---|---|
| A第一人称 | 约0.5秒撞盾，随后明显分离；反弹时兽体出现直立拉伸，落地后停顿偏长 | 保留接触，抽帧压缩空中阶段，落地后迅速接反击 |
| B怪兽肩后 | 约0.5秒刀刃接触肩甲，其后长时间保持接触姿态 | 只保留开头18帧，命中后切C |
| C贴地 | 有撞路障、碎块和落地，Aegis大部分时间保持随挥姿态 | 取开头至45帧并约两倍抽帧，压缩落地后的停留 |
| D俯拍 | 能交代双方位置，动作幅度有限 | 只留开头16帧作收尾 |

逐帧来源见[edit-map.json](edit-map.json)，源帧编号从0开始。剪辑段落：A32帧、B18帧、C24帧、D16帧。帧数和帧率已用ffprobe验证，关键画面已检查。

这版用于检验多机位动作节奏，不是完整十秒成片。跨镜头还有兽体尺寸/位置变化，C到D由刀变盾的过程没有拍出，A反弹期间有形体拉伸。原图及FL2V动作生成都还存在限制，不能称为无缝连续镜头。

若要完成原十秒计划，需要原FL2V十秒包01–03的实际渲染，选出侧面扑进、反击、追进等有效片段后整合。当前不以慢放、重复或停帧凑十秒。原始上传视频保存在sources/，文件名映射：A=EP3_A-pov_00001_，B=EP3_B-beast-ots_00001_，C=EP3_C-ground_00001_，D=EP3_D-overhead_00001_。
