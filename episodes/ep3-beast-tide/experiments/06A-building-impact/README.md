## 三镜头

|时间|内容|速度与摄影|
|---|---|---|
|0–1.25秒|巨掌逼近；约0.70秒击中右臂盾；肘肩压缩|逼近正常快速度；只有接触的约0.55秒慢镜头，短推进展示受力|
|1.25–2.60秒|突然拍飞，肩背先向建筑，双腿滞后|硬切回极快动作；人物先跑出原构图，相机再急摇追赶|
|2.60–6秒|约2.80秒肩背接触外墙；玻璃、墙体破裂，能量爆闪、局部坍塌，尘中显露人物|同一三分之四广角看清接触与破坏；短震动后稍拉开，保留洞口和坠落块体|

爆炸来自碰撞时装甲能量短暂外泄，表现为接触点橙金短闪、冲击尘浪与火花。不是无来源油罐爆炸。大块混凝土向下坠落，小碎片高速外射。四米左右的局部外墙及破损阳台边缘坍塌，整栋高楼保持站立；Aegis仍为1.88米，不能用撞倒整栋楼掩盖比例问题。

## 检查重点

1. 慢镜头只占接触瞬间；1.25秒之后有明显速度突变，不是全片缓慢漂浮。
2. Aegis和手掌迅速分离，人物实际改变位置，不能只有相机模糊。
3. 肩背碰墙在前，墙体破裂与爆闪在后；碎片与尘浪有方向和重力。
4. 尘雾不能从接触前就盖住动作，末尾至少能短暂看见Aegis。

时间表、速度变化和破坏范围都是生成目标，并非逐帧控制。本次还改变了时长和动作内容，不能当成仅改一项参数的对照实验。若模型无法明确区分慢镜和极速段，后期可分别处理接触与击飞段的速度；不要把错误接触靠闪光遮掉。现有参考图的精确比例仍未校准。
