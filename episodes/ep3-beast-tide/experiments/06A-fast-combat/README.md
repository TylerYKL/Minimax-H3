用户最新目标是快打斗。这版明确取消上一版接触慢镜，改成短接触、突然击飞、快速撞墙和立即脱险。详细保留空间、受力、运镜与特效因果，不用长时间展示每个动作。未渲染验证。

## 速度节点

- 约0.20秒：掌盾接触；0.60秒前已经分离。
- 0.60–1.30秒：被击飞，跨过数个窗格；相机不匀速陪飞。
- 约1.40秒：肩背撞墙，先接触与破裂，再能量短闪和碎石。
- 2–3秒：墙板继续下坠，Aegis短暂制动后喷射冲出；巨兽另一只手追击洞口下沿。
- 3–4秒：持续高速上冲，运动中结束。

这些是目标时序，不是模型保证的逐帧控制。当前模型可能把所有动作拉长；不能把重复缓慢贴盾判作成功的慢镜效果。这版6秒改4秒，并增加了立即追击，所以不是只改一个变量的性能测试。

## 通过标准

第一次闪光结束时人与手掌已分离；飞行段明显跨过背景窗格；墙体破坏后人物迅速继续行动。只出现更多光效但速度仍平缓，视为未达到快打斗目标。

旧版00011可以作为撞墙特效参考，但不要把它本身当成运动参考，否则可能继续引导缓慢节奏。该文件24fps本身不意味着慢动作，也不能仅提高播放帧率就补出正确受力。

若这版仍明显缓慢，下一步应核实兼容的基础模型推荐设置并进行对照，或制作更匹配的掌击视频参考；不再无限增加同义的速度形容词，也不盲目把4-step LoRA直接改为高步数。当前尚无证据断言瓶颈只在提示词或只在LoRA。

该实验保留在独立目录，不覆盖旧方案。结尾从建筑冲出上行，下一镜应接这条逃生轨迹；原06B的空中侧翻起点仍不直接兼容。正式75秒时间线尚未改动。
