# I2V 撞盾剪辑节奏测试

[剪辑版：1.208 秒](shield-impact-1.21s.mp4) · [原版：3.042 秒](source.mp4)

来源为用户上传的 EP3_10s_01_00003_.mp4。本次只做局部变速与裁剪，没有重新生成视频、插帧、加震屏或添加音效。

输出 864×480、24 fps、29 帧，静音。源帧编号从 0 开始：

- 0–9：保留扑进和首次接触，原速。
- 10、12、15、18：缩短贴盾过程。
- 20、23、26、29、32、35、38：加快分离及落地，约三倍速。
- 39–46：保留落地后的短暂缓冲，原速。
- 47–72：删除末尾待机。

这不是整体加速，且没有补出原片缺失的击飞动作。抽帧变速可能使运动更跳跃；用途是判断剪辑节奏，不代表动作质量已经达标。视频帧数及帧率已用 ffprobe 检查，接触关键帧已核对。
