# 单次十秒 FL2V 测试

本次是真正的**一个分组、一对首尾帧、一次约十秒生成**，不是三个短片拼接。已提供工作流和图片，尚未在H3运行。

1. 用ComfyUI打开 `single-10s-workflow.json`。
2. 确认模式FL2V，只有一个分组。将 `start.png` 上传首帧槽，`end.png` 上传尾帧槽，确认缩略图。
3. FL2VA UNET、25 steps、CFG 1、res_multistep/simple、shift 12/3、seed 888 fixed、864×480、24fps。沿用之前FL2V设置，Turbo/Combat保持旁路，静音导出。CLIP/VAE文件名按本机安装选择。
4. 长度243帧=10.125秒，符合17k+5；不要填240后误以为仍是精确十秒。只有一个243帧分组，不加载A–D多视角图、灰模视频或额外团队合照。
5. 提示词已经内置，也可单独查看prompt.txt。动作是撞盾反弹→拨爪→换刀斜斩→击飞撞路障→追进换盾。镜头保持同侧连续运动，避免长镜头同时承担多个硬切机位。

首尾图复用上个十秒包的01-start和03-end；尾帧中兽体透视偏大、构图与首帧有差异，是否产生体型变化需要实测。本次测试的是单次长段动作能力，不保证多次接触、武器切换和分秒执行成功。首尾帧只能约束端点。

出片后先保留完整243帧发回。若需要严格十秒，依据动作选择删去三个冗余帧，保留最后的目标尾帧；不要直接裁掉末尾三帧，也不要提前整体加速。最终接触压缩、变速和切点依据实际视频决定。

工作流仅完成静态连接、帧数、首尾文件引用检查，未实机验证。此包不含已生成的H3视频。
