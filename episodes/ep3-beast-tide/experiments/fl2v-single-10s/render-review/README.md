# 单段十秒 FL2V 实测

[严格十秒版](single-combat-exact-10s.mp4) · [原始243帧](source-243f.mp4)

用户上传EP3_FL2V_single10_00001_.mp4：864×480、24fps、243帧、10.125秒、静音。严格十秒版仅删除源帧45、104、171（从0计数），重新排列时间戳；保留首帧和最后目标帧，输出240帧/10.000秒。没有新增镜头、特效、音效或整体变速，也没有修复模型形变。时长、帧数和帧率已用ffprobe检查。

## 画面观察（时间对应原片，约值）

- 0–2秒：扑撞盾面，约0.6秒出现接触闪光，然后分离落地；主要因果关系成立。
- 2.3–3.2秒：岩兽再次向前扑抓，Aegis转盾应对；兽爪前伸阶段有拉伸感。
- 3.3–5.1秒：盾切成刀，举刀斩击完成；举刀段约3.6–4.8秒偏长，刀形与参考宽刃设计不完全一致。
- 5.2–6.4秒：岩兽空中后退并撞到路障，因果比短片拼接完整，但空中运动仍偏缓。
- 6.4–8秒：碎块落下，兽体恢复，Aegis姿态变化较少，没有特别明显的连续追进两步。
- 8–10秒：岩兽再次扑近，Aegis换回盾，最后回到目标尾帧附近；这多出来的扑近动作偏离了原提示词“横移、不再次冲撞”的安排，兽体姿态和体型仍需检查。

结论：单次FL2V长段在这一次样本中能够承载主要动作顺序，值得作为后续剪辑主线；不等于分秒、武器设计和快速击飞已经稳定可控。保留“单段主线+少量主观/贴地插镜”作为下一步方向，避免重复播放相同碰撞。当前严格十秒版只做时长规范化，未进行快打节奏重剪。
