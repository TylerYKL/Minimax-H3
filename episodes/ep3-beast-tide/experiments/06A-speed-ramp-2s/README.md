## 在 Director 中使用

1. 复制当前 06A 分组作为独立测试，选择 r2v，开启 Shared Params。
2. Shared/Common Prompt 替换为本目录 `common-prompt.txt`；当前分组 Prompt 全文替换为 `06A-group.txt`。不能把旧四秒提示词附加在后面，也不能在共享提示词开启时再粘贴 `06A-complete.txt`。
3. Picture 1–4 沿用原共享素材；Picture 5 沿用 Aegis 空中举盾参考图；Video 1 沿用 1.13 秒冲击参考视频。具体路径见 manifest.json。Picture 5 只提供装备外观，开场护盾必须关闭；Video 1 只提供接触后突然分离的节奏。
4. 分组目标时长设为 2.0 秒。保留 24 fps、seed 888、CFG 1、4 steps、euler/simple、video shift 12、audio shift 3，模型链为 UNET → ref2v Turbo 1.0 → Combat V2 0.4 → Director。
5. 本版 summary 已含 `prfight2, prfin1`，无需另加。渲染后检查视频内嵌输入，确认两个触发词和两层 LoRA 都实际进入任务。

若关闭 Shared/Common Prompt，则仅使用 `06A-complete.txt`，并手动确保相同 Picture 1–5 和 Video 1 仍绑定到分组。manifest.json 是人工配置说明，不是可直接导入的工作流或 mmxpack。

## 动作与摄影机时间表

| 时间 | 动作与特效 | 摄影机 |
|---|---|---|
| 0.00–0.15 | Aegis 空中悬停，脚底持续喷射；巨爪高速进入 | 侧面中广景，建立巨爪—人物—建筑路线 |
| 0.15–1.00 | 爪子减速为慢镜；前缘空气折射、尘粒被推开；盾尚未展开 | 小幅推近，保留双方间距与全身 |
| 1.00–1.10 | 恢复高速，右前臂瞬间展开金色蜂巢盾 | 延续同一镜头，不切掉开盾过程 |
| 1.10–1.18 | 一次掌盾接触；短闪、盾面内凹、金色波纹；肘肩躯干一起后折，喷焰熄灭，人与手立即分离 | 一次短促震动，冲击闪光目标为 1–2 帧，不停格 |
| 1.18–1.35 | 背部领先瞬间击飞，白色残影连接起点与撞击点 | 硬切高位俯视固定广角，保留建筑外墙可见，左到右方向不变 |
| 1.35–2.00 | 背部先撞墙，墙体内陷后碎裂；楼板断开，上层建筑开始下沉，碎石与尘土扩散 | 保持俯视，不切回人物贴墙特写 |

两秒内展示建筑开始坍塌，而非整栋楼已经落地。结尾人物仍在撞击缺口内，没有原版向上飞离或巨兽第二次追击。原 06B 起始动作不能直接衔接此结尾。

## 两秒与实际输出长度

官方提示词 Skill 的常规建议是 4–15 秒，本次按用户要求做两秒短片实验，不宣称属于官方验证的时长配置。已检查本地 Director 源码的 durationToMiniMaxFrames：按 17k+5 对齐帧数，输入 2.0 秒、24 fps 对应 56 帧，约 2.33 秒。用户安装版本可能不同，以实际输出为准。

动作目标仍在前两秒内完成，多出的尾部只继续坍塌。精确时间码和 1–2 帧闪光属于导演目标，不是模型逐帧执行保证。若实际动作准时完成，可在剪辑中取前两秒；若动作延后，直接裁剪会丢掉撞楼结果，应先复核生成节奏。

## 本轮验证重点

- 初始护盾关闭，推进器支撑悬停；到接触前才瞬间开盾。
- 慢动作只用于逼近。击中后不能继续慢推盾或缓慢飞行。
- 白线随人物位移出现，起点不再残留另一个 Aegis。
- 俯视镜头同时交代出发点、路线与建筑；不能整段变为贴身追拍。
- 身体接触墙体在先，结构破坏和尘土在后；不能用闪光遮住全部过程。
- 保持人兽比例、右臂护盾和两名可见主体，不出现刀或额外人物。

本轮是新镜头方案，改变了动作、时序和机位，不是 Combat LoRA 的单变量效果测评。参考视频仍有原字幕，若再次出现伪文字，下一轮应单独更换干净的运动参考；先不同时修改采样器和 LoRA 强度。
