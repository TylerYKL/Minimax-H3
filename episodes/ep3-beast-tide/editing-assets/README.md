## 配音与后期

voiceover-cue-sheet.csv采用UTF-8 BOM，可在Excel中打开。时间均为各素材本地时间，不是整集时间码。台词与配音人留空/待定，避免提前锁定未经确认的对白。确定总剪辑后再填写精确台词入出点。

manifest.json记录帧率、分辨率、帧数、音轨存在情况、原始路径及SHA-256。素材按现有文件原样复制，未再次压缩。音轨存在仅表示文件有音轨，不代表已有可用配音。

EP3-editing-assets.zip包含全部clips、manifest和配音表。
