## 4-step Turbo使用说明

采用短片段、明确接触顺序和较少内部切镜来降低动作复杂度。这是提示词策略，不是已验证的LoRA专属参数。采样器、调度器、CFG、LoRA强度沿用用户已跑通的配置；提交前确认界面支持的时长、参考模式与分辨率。

片段06、07、08、11已合并最新多机位修订。每段的Shot编号和切镜时间从零开始，换镜保留运动方向，接触后再切反应。先测试06、07，再处理其余段落。

时长均为目标值，应按实际输出检查与修剪。参考图用于外观、构图和动作关系，不自动锁定首帧。分镜多宫格含文字箭头，不直接作为主体参考。若选用上一段的结束帧作新参考，需同步修改附件映射与定义。

静态生成图仍有透视、刀盾左右臂、桥梁损坏和角色细节漂移，不能视为尺寸或连续性的精确验证。文字中的身高、装备侧别、边界和损伤状态优先，正式生成前按镜头检查参考图。

台词和连续配乐在后期添加，见story.md。源提示词保留物理音效，不生成对白、字幕或配乐。精确冲击停顿、闪帧及速度变化在剪辑中完成。
